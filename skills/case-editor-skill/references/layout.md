# Вёрстка (опциональный шаг)

По умолчанию **не запускается**. Работает на прямой запрос: «сверстай кейс», «собери страницу», «сделай слайды», «сделай HTML».

Зачем это нужно: у автора скилла узкое место — не текст, а сборка визуала. Текст пишется за вечер, а страница висит неделями. HTML-раскладка снимает часть этой работы: агент отдаёт страницу, где кадры-заглушки уже стоят на своих местах с описаниями внутри.

## Что делает шаг

1. Собирает один HTML-файл с инлайн-стилями, без зависимостей, открывается двойным кликом.
2. Текст кейса идёт как есть.
3. На месте каждого `[📷]` / `[🎥]` — плейсхолдер правильной пропорции с номером и описанием внутри. Дизайнер вставляет свои файлы и удаляет плейсхолдеры.
4. Адаптив: 1440, 1024, 390.
5. В конце — скрытый блок с производственным планом (по желанию, для печати перед работой).

## Правила раскладки

- **Ширина текста:** 680 px на десктопе, 100% минус 40 px на мобильном. Длинная строка не читается.
- **Медиа:** до 1200 px, шире контейнера текста. Кадр должен быть заметно шире абзаца, иначе теряется разница между текстом и медиа.
- **Вертикальные отступы:** 80 px между блоками на десктопе, 48 px на мобильном.
- **Две ступени типографики** (приём ONY): «широкий» абзац 32/38 px, обычный 18/28 px. Первый абзац после лида — широкий.
- **Пропорции через `aspect-ratio`**, а не фиксированную высоту: плейсхолдер сразу верного размера, без скачков при загрузке.
- **Тема:** светлая по умолчанию. Тёмная — только если у проекта тёмная айдентика.

## Скелет

```html
<!doctype html>
<html lang="ru">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>…</title>
<style>
  :root{--fg:#111;--muted:#666;--bg:#fff;--line:#e5e5e5;--max:680px;--media:1200px}
  *{box-sizing:border-box}
  body{margin:0;background:var(--bg);color:var(--fg);
       font:400 18px/1.6 -apple-system,BlinkMacSystemFont,"Segoe UI",Roboto,sans-serif}
  .wrap{max-width:var(--media);margin:0 auto;padding:0 20px}
  .text{max-width:var(--max);margin:0 auto}
  h1{font-size:44px;line-height:1.1;letter-spacing:-.02em;margin:96px 0 32px}
  p{margin:0 0 28px}
  .lead{font-size:32px;line-height:1.3;letter-spacing:-.01em;margin-bottom:40px}
  figure{margin:80px 0}
  .ph{position:relative;display:flex;align-items:flex-end;padding:16px;
      background:#f4f4f4;border:1px dashed #d0d0d0;color:var(--muted);font-size:13px;line-height:1.4}
  .ph.r45{aspect-ratio:4/5} .ph.r169{aspect-ratio:16/9} .ph.r11{aspect-ratio:1/1}
  .ph.r916{aspect-ratio:9/16} .ph.r32{aspect-ratio:3/2}
  img,video{width:100%;height:auto;display:block}
  figcaption{max-width:var(--max);margin:12px auto 0;font-size:14px;color:var(--muted)}
  @media(max-width:600px){
    h1{font-size:32px;margin:56px 0 20px}
    .lead{font-size:24px;line-height:1.35}
    figure{margin:48px 0}
    body{font-size:17px;line-height:1.6}
  }
</style>
</head>
<body>
<main class="wrap">
  <h1>Название кейса</h1>
  <figure><div class="ph r45">00 · 4:5 · Описание обложки</div></figure>
  <div class="text">
    <p class="lead">Лид, 50–90 слов.</p>
    <p>Абзац.</p>
  </div>
  <figure><div class="ph r169">01 · 16:9 · Описание кадра</div></figure>
  <div class="text"><p>Абзац.</p></div>
</main>
</body>
</html>
```

## Как вести себя в диалоге

- Не верстай, пока не попросят. Это явно оговорено в SKILL.md.
- Спроси только три вещи: куда класть файл, нужна ли тёмная тема, нужны ли плейсхолдеры или сразу `<img src>` с путями, которые даст пользователь.
- Не тяни шрифты с внешних CDN: страница должна открываться без интернета.
- Не вставляй аналитику, куки-баннеры, скрипты.
- Отдай один файл `case.html`, а не набор ассетов.

## Слайды

Если просят «слайды» — это не PDF, а последовательность кадров для Behance: 1400×788 или 1400×1750 (4:5), с полями 80 px, где текст набран крупно и читается с телефона. Тот же HTML, но каждый блок — `section` фиксированного размера для скриншота.

## Чего шаг не делает

- Не заменяет дизайн: раскладка нейтральна, чтобы не спорить с материалами.
- Не подбирает шрифты проекта. Если у бренда есть гарнитура, попроси файлы; иначе системный стек.
- Не публикует и не деплоит. Файл остаётся у пользователя.
