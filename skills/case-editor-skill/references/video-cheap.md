# Дешёвые видео

> **Личное ограничение автора скилла.** Мне нравятся видео в кейсах, но я не моушен-дизайнер, и тяжёлая графика съедает дни. Этот файл — про приёмы, которые дают живой кадр за час, а не за неделю. Если ты используешь скилл у себя и моушен для тебя не проблема, удали файл и строку про него в SKILL.md — остальное продолжит работать.

## Правило

Одно движение, один слой, три-шесть секунд, без звука, луп. Всё, что требует кейфреймов по сетке, персонажа с риггом или 3D-сцены, — не наш вариант.

Видео в кейсе решает одну задачу: **показать изменение во времени**. Статика показывает, как выглядит. Видео показывает, как работает. Если в кадре ничего не меняется — это не видео, а картинка, которая весит 8 МБ.

## Приёмы по времени

**15 минут**

- **Запись экрана прокруткой.** Открыл макет в браузере, прокрутил, записал. Для сайта, лендинга, длинной страницы — самый честный способ показать, что там внизу.
- **Курсор по прототипу.** Figma-прототип, включил запись, прошёл два-три клика. Показывает логику перехода.
- **Смена состояний.** Один экран, два-три состояния подряд с задержкой по 0,5 с. Работает для тёмной темы, ошибки, загрузки.
- **Скролл по сетке.** Сетка работ (Behance, лента) прокручивается под курсором.

**30–60 минут**

- **Параллакс из одного слоя.** Картинка и фон движутся с разной скоростью. Собирается в After Effects за пять кейфреймов или в CSS на сайте.
- **Сборка знака.** Элементы знака выезжают на место по очереди, 0,15 с задержки. Шесть слоёв, простые `position`-анимации.
- **Паттерн в движении.** Плитка паттерна едет бесшовно сбоку. Один слой, `offset` по кругу.
- **Тень и свет.** Статичный объект, по нему проходит градиентная полоса. Создаёт объём без 3D.
- **Перебор палитры.** Фон меняет цвет, объект остаётся. Пять шагов по 0,8 с.

**1–2 часа**

- **Типографический набор.** Строка набирается по буквам или слово меняется на другое. Работает для названий и для заголовков кейса.
- **Смена носителей.** Один знак, четыре носителя, кадр меняется каждые 1,2 с. Даёт ощущение системы без единого мокапа.
- **Съёмка на телефон.** Напечатанное на крафте, лист под лампой, поворот на 10 градусов. Телефон на штативе из книг, дневной свет у окна.

**Не делать**

- Рендеры 3D-сцен и турнтейблы.
- Анимацию персонажа с риггом.
- Кинетическую типографику с покадровой подгонкой.
- Всё, где больше двух дорожек и где нужен звук.
- Всё, что требует плагинов, которых у тебя нет.

## Технические требования

- **Длина:** 3–6 секунд. Больше 8 почти никто не досматривает, и файл тяжелеет вдвое.
- **Звук:** нет. `muted` обязателен, иначе браузер не даст автоплей.
- **Луп:** первый и последний кадр совпадают, иначе виден рывок. Приём: продублировать первый кадр в конце.
- **Кодек:** H.264 в MP4 для площадок, WebM и MP4 для своего сайта, плюс постер-кадр в WebP — иначе на медленной связи видна пустота.
- **Вес:** до 3 МБ на файл, 1080 px по длинной стороне достаточно. На Behance загружается MP4 до 50 МБ, но 3 МБ грузится заметно приятнее.
- **Атрибуты:** `<video autoplay muted loop playsinline preload="metadata" poster="…">`. Без `playsinline` iPhone развернёт видео на весь экран.

## Что писать в описании видео

```
[🎥 02 · 16:9 · 5 секунд. Экран каталога прокручивается сверху вниз, фильтр
прилипает к верху. Без звука, луп. Зачем: показывает, что фильтр остаётся
доступным на всей длине списка — это и было решением.]
```

Обязательно: длина, что происходит, звук, зачем. Из этого описания понятно, сколько работы, и это можно сделать за полчаса.

## Если видео нет совсем

Это нормально. Сильный статичный кадр работает лучше плохого видео. Замена:

- **Пара «до/после»** двумя кадрами подряд.
- **Раскадровка** из трёх статичных кадров, показывающих изменение.
- **Зум на детали** — тот же кадр, но второй раз крупно.
- **Гифка** вместо видео: 500 КБ, тот же эффект для короткой петли.

## Чего избегать в сценарии

- Трёх видео подряд в одном кейсе: читатель устаёт и начинает листать.
- Видео, которое дублирует статичный кадр рядом.
- Видео с текстом, который нельзя прочитать за 4 секунды.
- Видео, для которого нужен сценарий, актёры или съёмочный день.
