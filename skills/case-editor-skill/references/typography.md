# Типографика

Цель: текст можно скопировать на площадку, и он не развалится. Ни одного висящего предлога, ни одной кавычки-лапки.

## Неразрывный пробел

NBSP (`\u00A0`) ставится там, где перенос оставит строку без смысла.

**1. Короткие предлоги и союзы перед словом.** Всегда: `в`, `к`, `с`, `у`, `о`, `об`, `на`, `за`, `по`, `из`, `от`, `до`, `для`, `при`, `над`, `под`, `без`, `про`, `через`, `и`, `а`, `но`, `не`, `ни`, `что`, `как`, `же`, `ли`.

Правильно: `в&nbsp;основе`, `на&nbsp;полке`, `не&nbsp;картинка`, `по&nbsp;форме`.
Неправильно: `в основе`, `на полке`.

Важно: `не` отделяется NBSP **только от следующего слова**, но не от знака тире: `не&nbsp;просто`, при этом `— не просто` остаётся как есть.

**2. Число и следующее за ним слово.** `40&nbsp;машин`, `12&nbsp;мм`, `3&nbsp;узла`, `194&nbsp;слайда`, `2026&nbsp;год`.

**3. Число и его единица или знак.** `+1,1&nbsp;п.п.`, `39&nbsp;%`, `2&nbsp;м`, `15&nbsp;кг`, `5&nbsp;секунд`.

**4. Инициалы и сокращения.** `И.&nbsp;И.&nbsp;Иванов`, `т.&nbsp;е.`, `т.&nbsp;д.`, `и&nbsp;т.&nbsp;п.`.

**5. Тире «—» прижимается к предыдущему слову**, а после него ставится обычный пробел: `макет — не&nbsp;картинка`. Внутри конструкции с запятыми тире может получать пробелы с двух сторон: `система — три узла — работает`.

**6. Слово и следующее за ним длинное тире в конце строки** — частая причина висячего тире. Правило: тире никогда не начинает строку, поэтому перед ним ставится NBSP: `система&nbsp;— три узла`.

**7. После точки в конце предложения** NBSP не нужен. Не путай с сокращениями.

**Требование пользователя:** «не должно быть висящих предлогов и переносов строк при помощи Enter там, где должен быть неразрывный пробел». То есть **никогда не расставляй переносы руками**: ни `Enter` внутри абзаца, ни `<br>`. Абзац — одна строка в markdown, переносы делает площадка.

## Кавычки

Только ёлочки: `«Норма»`, `«Крестьянские ведомости»`.

Внутри ёлочек — лапки: `«он сказал „сделайте персонажа“»`.

Никогда: `"Норма"`, `„Норма"`, `"Норма"`.

Апостроф в иностранных словах — типографский: `'` (`o'clock`), но в русском тексте его почти нет.

## Тире и дефис

- **Дефис** `-` внутри слова: `дизайн-система`, `бренд-платформа`, `веб-дизайн`.
- **Короткое тире** `–` в диапазонах: `2024–2026`, `10–15 слайдов`, `300–700 слов`.
- **Длинное тире** `—` в предложении, с пробелами: `Система — не&nbsp;картинка`.

Не путать: `300-700` неправильно, `300–700` правильно.

## Пробелы

- Один пробел после точки и запятой, не два.
- Пробел перед знаком `%` не нужен в русской традиции, если число с процентом: `39%`. Пинкман пишет `+1,1 п.п.` с пробелом перед `п.п.` — это допустимо, главное единообразие.
- Пробелы внутри скобок не ставятся: `(например, так)`, не `( например, так )`.
- Многоточие — один символ `…`, не три точки.

## Как это делается технически

В markdown NBSP можно вставить символом напрямую (он невидим, но копируется) — это основной способ, площадки его сохраняют.

Скрипт `scripts/typograph.py` расставляет NBSP, меняет кавычки и тире, чистит двойные пробелы и проверяет, не осталось ли висячих предлогов. Запуск:

```
python scripts/typograph.py case.md            # проверить и показать отчёт
python scripts/typograph.py case.md --write    # переписать файл
```

Скрипт не трогает содержимое блоков кода и строки с `[📷`/`[🎥`, кроме расстановки NBSP.

## Проверка перед сдачей

- Поиск по тексту `[ ]` + короткое слово + обычный пробел: должно быть ноль совпадений.
- Поиск `"` и `„`: ноль.
- Поиск ` - ` (дефис с пробелами): ноль, это должно быть ` — `.
- Поиск двух пробелов подряд: ноль.
- Ни одного `Enter` внутри абзаца: каждый абзац — одна строка.
- Числа перед существительными: проверь `40 машин`, `12 мм`, `3 узла`.

## Цитаты

Прямая речь клиента или команды — отдельным абзацем, начиная с `>`, с ёлочками внутри и указанием, кто говорит:

```
> «Работа была непростым, но ценным опытом. Не всё шло гладко, но ребята были готовы слушать».
> Имя Фамилия, должность, компания
```

Цитата без атрибуции — не цитата. Имя и роль указываются только если пользователь разрешил; иначе — «руководитель отдела найма» без фамилии.

Цитату не сокращай до похвалы. В цитате ценно трение, а не комплимент.
